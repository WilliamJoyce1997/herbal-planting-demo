## 功能覆盖

- 基地切换后的指标和地图联动，地块维护、排序和删除保护。
- ECharts 渲染、切换、侧栏折叠后 ResizeObserver 适配。
- 土样报告及来源，人工 pH 数值校验与记录刷新恢复，视频离线和录像未接入提示。
- 指定员工任务创建、执行、退回重提、审核通过及刷新恢复。种植节点重叠时可分别点击，并可生成关联任务。
- 考勤先后顺序、重复提交和跨日行为。巡检、照片压缩预览、异常告警联动及确认到关闭的处理历史。
- 灌溉与采收修改后统计更新。通过 SheetJS 回读实际下载的 XLSX，核对新增的用水数值。
- 存储损坏回退、空间不足下业务状态保持以及恢复范围。
