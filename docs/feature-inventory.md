## 数据与边界

种植档案含 2 个虚构基地、10 个地块、5 个药材品种。应用用稳定 ID 建立联系。灌溉趋势按完成日期统计，记录区还可查看近期排程。计划进度按已完成计划节点计算。产量按鲜品、干品分别计算，单位面积使用实际采收记录面积。

演示图片与地图无真实测绘或监控信息。照片在浏览器中限 1 MB 输入，缩放后压缩为 JPEG，与业务记录一起写入项目专属 localStorage。读取失败时回退到演示样本。空间不足时本次更新保留原状态。

暂未接入真实视频与回放、气象、物联网、定位、认证和权限、多端协同，以及生产级质检报告流转。基地、批次和设备使用本地样本档案。外部设备验收、AI、预测、自动灌溉和 PRD 的后续阶段在正式系统范围内。
